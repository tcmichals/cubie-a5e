Subject: [PATCH v3 0/7] Add Allwinner A523 message box and XuanTie E906 remoteproc support

This series adds support for the Allwinner A523/A527/T527 (sun55i) hardware
message box and the accompanying T-Head XuanTie E906 RISC-V co-processor.

Changes since v2:
https://lore.kernel.org/linux-sunxi/20260927002021.797069-1-tcmichals@gmail.com/

Major changes in v3:
  - Mailbox: Describe and enable bus clocks and resets for all four
    hardware banks; an unclocked bank drops writes.
  - Mailbox: Clear IRQ status after FIFO drain to prevent duplicate
    interrupts.
  - RemoteProc: Consolidate to a single bidirectional mailbox channel
    (<&msgbox 9>).
  - RemoteProc: Defer mailbox rx callbacks to an ordered workqueue to
    prevent sleeping-in-atomic issues on non-RT kernels.
  - Bindings: Convert reg-names, clocks, resets, and memory-regions to
    fixed positional lists; drop "schema" from subjects (Krzysztof).
  - KUnit: Focus tests on driver logic; place test patches last (patches 6
    and 7).

Testing:
Tested on a Radxa Cubie A5E (Allwinner A527) running Linux 7.1 (PREEMPT_RT
and non-RT kernels with lock debugging enabled):
  - KUnit: 26/26 msgbox and 25/25 remoteproc tests pass (51/51).
  - RPMsg ping-pong and multi-worker stress tests pass with 0 errors.
  - Rebased on next-20261015: dt_binding_check, dtbs_check, and checkpatch
    are clean.
