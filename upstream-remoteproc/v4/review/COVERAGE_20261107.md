## Findings

1. **KUnit fixture locked an uninitialised mutex** (fixed, `c22242e478f5`, TODO
   V4-LOCKDEP-KTEST). `test_functional_shutdown_flushes` started a channel on the plain fixture:
   no TX line, `tx_irq_lock` never initialised. On the first lockdep boot: "trying to register
   non-static key", and lockdep turned itself off for the rest of the boot. `startup()` also
   failed with -EINVAL, so the test checked a channel that was never started. Not visible under
   UML before because the UML runs had no lockdep. The sweep's health check missed it too; it now
   catches lockdep, debug-object and RCU reports and `debug_locks: 0`.
2. **Remoteproc core use-after-free in `rproc_add()`** (not our code, TODO CORE-RPROC-ADD). When
   `device_add()` fails, `rproc_add()` calls `put_device()`, which drops the only reference
   (`rproc_alloc()`'s) and frees the rproc; it then calls `rproc_char_device_remove()` on it, and
   the driver's `devm_rproc_free()` puts it again. Seen as `kobject_put()` warnings on a freed
   kobject whose name is a uevent string (`OF_FULLNAME=/soc/remoteproc@7130000`). Same code in
   next-20261105. Every driver that frees its rproc after a failed `rproc_add()` is affected.
3. `devm_ioremap_resource()` reports a failed allocation inside `__request_region()` as -EBUSY
   "can't request region": expected, not a leak (checked: the region is free in `/proc/iomem`
   after every failed probe).

## Reproduce

```sh
# UML (scratch worktree with tools/uml-gcov-workarounds.patch, see sweep_gcov.py)
tools/sweep_gcov.py uml --build-dir ../kunit-uml-gcov --out uml.json
# Board, gcov kernel installed
tools/run_full_sweep.py --gcov-build-dir ../kobj-v4-cov --json-out sweep.json
ssh root@192.168.3.3 /root/fail_nth_drivers.sh          # copy tools/fail_nth_drivers.sh first
tools/sweep_gcov.py board --build-dir ../kobj-v4-cov --label fail-nth --out failnth.json
tools/dt_error_tests.sh --gcov-build-dir ../kobj-v4-cov --out-dir dterr
# ret_override: see the comment at the top of tools/ret_override/ret_override.c
tools/sweep_gcov.py board --build-dir ../kobj-v4-cov --label ret-override --out retov.json
tools/sweep_gcov.py merge sweep.json uml.json failnth.json dterr/*.cov.json retov.json
```

A rebuild of `kobj-v4-cov` replaces the `.gcno` files: take every board snapshot against the
build that is on the board (the JSON files keep line counts, so they merge across builds of the
same source).
