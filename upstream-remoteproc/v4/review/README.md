# v4 own reviews

Reviews of the v4 code before sending, one file per review (`<KIND>_REVIEW_<YYYYMMDD>_<area>.md`,
as in [../../v3/review/](../../v3/review/)).

Each finding gets an ID and one of: fixed (commit), or put to the owner as a yes/no (answer and
date). No finding is closed as "left as is" or by citing one peer driver only; see
[../PRESEND_CHECKLIST.md](../PRESEND_CHECKLIST.md) §3.
